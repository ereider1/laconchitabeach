LA CONCHITA BEACH — TRANSPARENT FAVICON PACKAGE

This package uses the circular palm-tree, sunset, and ocean logo with a transparent
outer background, so the circular badge works on both light and dark page backgrounds.

Included:
- favicon.ico (multi-size browser icon)
- PNG favicons: 16, 32, 48, 64, 128, 192, 256, and 512 px
- apple-touch-icon.png (180 x 180)
- site.webmanifest (optional PWA metadata)

Upload these files to your site's public/root directory.

Add inside the HTML <head>:
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="192x192" href="/favicon-192x192.png">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">

The image itself has a transparent exterior; the white and navy rings remain part of the logo.
